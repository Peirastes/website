## Quick Start Guide

### Step 1: Visit Wikimedia Commons
Go to: https://commons.wikimedia.org/

### Step 2: Search for the Scientist
- Search in the top bar
- Look for portraits, paintings, photographs
- Prefer: Public Domain, high resolution, portrait orientation

### Step 3: Download the Image
- Click on the image
- Click "Download" or "Original" link
- Save with the filename listed above to: `C:\Users\Cole\Dropbox\Website\images\timeline_images\`

### Step 4: Alternative Sources (if Wikimedia doesn't have it)
- Wikipedia article about the person (usually has image)
- Internet Archive (archive.org)
- LibraryOfCongress.gov
- Google Images (with "Public Domain" filter)

### Step 5: Organize and Commit
Once you've downloaded all images:
1. All files go in: `images/timeline_images/`
2. Use exact filenames from this guide
3. Git add and commit: `git add images/timeline_images/`

## Notes

- Most historical figures have multiple portrait options
- Prefer classical paintings/busts for ancient/medieval figures
- Prefer photographs for 19th-20th century figures
- Higher resolution is always better (can be resized)
- Public domain means free to use, no attribution needed (but nice to have)
- Wikimedia Commons has **millions** of public domain images

Good luck! Let me know if you'd like help downloading or organizing the images once you've collected them.
