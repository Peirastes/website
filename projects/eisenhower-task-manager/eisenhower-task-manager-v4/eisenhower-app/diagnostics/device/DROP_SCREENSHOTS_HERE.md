# Drop your phone/tablet screenshots here

Save real-device screenshots into this folder (via the Dropbox mobile app — star/favorite
it for quick access). Then tell Claude what's off + the device + orientation.

Optional naming hint: `device-orientation-issue.png` (e.g. `iphone15pro-portrait-keyboard.png`).

These are the ground truth for anything device-specific (notch/safe-area, keyboard,
home-screen PWA chrome, real Safari fonts) that headless captures can't show.
