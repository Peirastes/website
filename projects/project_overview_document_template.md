## AI Agent Instructions

When populating this template:

1. **Prioritize clarity over comprehensiveness.** This document should be readable in 5-10 minutes.

2. **Be direct about problems.** Vague concerns help no one. Name the actual issues.

3. **Distinguish confidence levels.** Flag what's certain versus what's estimated or assumed.

4. **Update meaningfully.** Only revise when something substantive changes—not on a schedule for its own sake.

5. **Preserve institutional memory.** When issues are resolved or milestones pass, briefly note what happened rather than simply deleting them.
