================================================================================
MAIN AUTOMATION WRAPPER (Production Daily Use)
================================================================================

SCRIPT: run_daily_update.py
PURPOSE: Execute full data generation pipeline with validation and logging
USE CASE: Scheduled daily via Task Scheduler / cron
WHEN TO RUN: Automatically at 06:00 UTC (configured in Task Scheduler)

MANUAL RUN:
  cd scripts
  python run_daily_update.py

EXPECTED DURATION: 60-180 seconds (1-3 minutes)

OUTPUT:
  - Generates all asset JSON files
  - Creates timestamped log in logs/ directory
  - Saves status to logs/last_run_status.json
  - Returns exit code 0 (success) or 1 (failure)

WHAT IT DOES:
  1. Runs generate_ecdo_watch_data.py
  2. Validates all output JSON files
  3. Checks data freshness
  4. Reports success/failure
  5. Creates audit trail in logs


================================================================================
HEALTH CHECK (Daily Monitoring - Recommended)
================================================================================

SCRIPT: healthcheck.py
PURPOSE: Quick status check WITHOUT generating new data
USE CASE: Daily verification, pre-deployment checks, monitoring systems
WHEN TO RUN: Every morning after 06:00 UTC run

MANUAL RUN:
  python scripts/healthcheck.py

EXPECTED DURATION: 2-5 seconds

OUTPUT:
  [OK] Last run successful (115.3s)
  [OK] Kp Index (14-day) (10 minutes)
  [OK] LOD (90-day) (10 minutes)
  [OK] Magnetometer (60-day) (4.9 hours)
  [OK] Kp range valid (0-9 range OK)
  [OK] LOD range valid (±10 ms OK)
  [FAIL] Some checks failed — Review above for issues

EXIT CODE: 0 (healthy) or 1 (issues detected)

WHAT IT CHECKS:
  1. Last run status file
  2. Data file freshness (<24h old)
  3. JSON file validity
  4. Data ranges & quality
  5. Recent log for errors/warnings

EXPECTED DURATION: 5-10 seconds

OUTPUT:

  Length of Day (LOD) Completeness........ 100.0%
  Average Duration........................ 115.3 seconds
  Success Rate............................ 100.0%
  Errors (30 days)........................ 2

WHAT IT REPORTS:
  1. Data completeness (% valid points)
  2. Per-source statistics (min/max/mean/stdev)

================================================================================
EXIT CODES & INTERPRETATION
================================================================================

EXIT CODE 0 = SUCCESS
  - All checks passed
  - System is healthy
  - No action required

EXIT CODE 1 = FAILURE
  - Some checks failed
  - Review output above for details
  - Follow Emergency Procedures in README

================================================================================
TROUBLESHOOTING
================================================================================

SCRIPT WON'T RUN:

  Error: "Python not found"
  → Install Python 3: https://www.python.org/downloads/
  → Verify: python --version

  Error: "ModuleNotFoundError: No module named 'pandas'"
  → Install dependencies: pip install -r requirements.txt
  → From: scripts/ directory

  Error: "FileNotFoundError"
  → Verify working directory is correct
  → cd scripts before running


SCRIPT HANGS:

  healthcheck.py hangs for >10 seconds
  → Kill with Ctrl+C
  → Check if assets/ JSON files exist
  → Run: python healthcheck.py (verbose mode would show where it hangs)

  data_quality_metrics.py hangs
  → Kill with Ctrl+C
  → Check if logs/ directory exists
  → Verify disk space


UNEXPECTED OUTPUT:

  [FAIL] checks when data is recent
  → Run: python verify_dashboard.py
  → Check if JSON files are corrupted
  → Re-generate with: python run_daily_update.py

  Data shows as "Not checked"
  → Latest log file might be corrupt
  → Try running: python run_daily_update.py
  → Then re-check: python data_quality_metrics.py


================================================================================
CHECKING RESULTS
================================================================================

After running scripts, check these files:

  1. logs/last_run_status.json
     → Last run success/failure and error message

  2. logs/ecdo_watch_YYYYMMDD_HHMMSS.log
     → Detailed execution log (most recent file)

  3. assets/*.json
     → Generated data files (check modification times)

  4. Browser console (F12)
     → Any JavaScript errors in dashboard
