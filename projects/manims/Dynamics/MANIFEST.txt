================================================================================
THE 4 ANIMATED SCENES
================================================================================

SCENE 1: RectangularCoordinatesDerivation
  Duration: 2-3 minutes
  Teaches: Basic x, y, z coordinate system
  Key Equations: Position, Velocity, Acceleration
  Best For: Introduction to kinematics

SCENE 2: CylindricalCoordinatesDerivation
  Duration: 3-4 minutes
  Teaches: Radial-angular coordinate system
  Key Equations: Unit vector rotation, polar components
  Best For: Orbital and rotating systems

SCENE 3: NormalTangentialCoordinatesDerivation
  Duration: 3-4 minutes
  Teaches: Path-following coordinate system
  Key Equations: Tangential and centripetal acceleration
  Best For: Motion along curves (projectiles, etc.)

SCENE 4: ComparisonTable
  Duration: 2-3 minutes
  Teaches: When to use each system
  Shows: Side-by-side comparison
  Best For: Course review and reference

TOTAL VIDEO DURATION: ~12 minutes

================================================================================
PEDAGOGICAL APPROACH
================================================================================

This system implements the 3Blue1Brown educational philosophy:

✓ Show phenomena BEFORE naming them
✓ Start with intuition, move to formalism
✓ Use color semantically (velocity=blue, acceleration=red)
✓ Smooth, careful animations (not jarring)
✓ Pauses for processing
✓ Multiple representations (geometry + algebra)
✓ Progressive complexity
✓ Inventing math (discovery-based)

Each scene follows this structure:
  1. Introduce coordinate system visually
  2. Define equations step-by-step
  3. Show derivation explicitly
  4. Highlight key components
  5. Final summary with comparison

Result: Students understand not just formulas, but WHY they exist.
